## Agent skills

### Issue tracker

Track issues and specs as local Markdown files under `.scratch/<feature>/`. Read `docs/agents/issue-tracker.md` before creating or updating tasks.

### Triage labels

Use the five default triage roles in each issue's `Status:` field. Read `docs/agents/triage-labels.md` when assigning a status.

### Domain docs

This is a single-context repository. Before exploring code, read `docs/agents/domain.md` for glossary and ADR consumer rules.
